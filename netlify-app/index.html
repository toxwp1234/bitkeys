What is this?

Every square is one private key — one possible Bitcoin wallet.

There are 2²⁵⁶ of them: more than the atoms in the observable universe. This map lets you walk them.

Click a patch and it derives that square's real Bitcoin addresses. Every one is empty — landing on a funded wallet is a ~10⁻⁴¹ event you will never see.

It's a map for feeling the scale, not a tool for finding coins.
