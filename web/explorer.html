Hits are effectively impossible (~10⁻⁴¹ per cell). This is a tool for feeling the scale of the keyspace — not for finding coins.

Each cell is one private key. Moving the cursor derives the real Bitcoin address for every key in the square and checks it against 56.2M funded addresses. Green = funded (you will never see one). Scroll = zoom · Shift+scroll = cursor size · drag = pan. click minimap to teleport. Explored cells stay lit as a trail.
